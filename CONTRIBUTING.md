# Contributing to ManuFX Portfolio

Thank you for your interest in contributing! Whether reporting a bug, suggesting a feature, or improving documentation, all feedback is appreciated.

## Quick Guidelines

1. **Bug Reports & Features**: Please open an issue using the appropriate template in `.github/ISSUE_TEMPLATE/`.
2. **Pull Requests**:
   - Fork the repository and create your branch from `main`.
   - Ensure `npm run lint` passes without errors.
   - Run `npx tsc --noEmit` to verify type safety.
   - Run `npm test` to verify test suite passing.
   - Commit with clear, conventional commit messages (`feat: ...`, `fix: ...`, `docs: ...`).

## Response Commitment

I actively monitor this repository and review new issues and pull requests **within 24 hours**.

## Code of Conduct

Please maintain a respectful, constructive, and inclusive environment for everyone.
